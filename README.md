# Binaire

Remplis la grille de soleils et de lunes : jamais trois pareils à la suite, autant de chaque par ligne et par colonne, et deux lignes jamais identiques.

Grilles de 6 × 6, 8 × 8 ou 10 × 10, générées avec une solution unique. Les cases de départ sont fixes. Remplis le reste en respectant les trois règles ; le chrono garde ton record par taille.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Binaire → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
